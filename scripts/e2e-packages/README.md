# בדיקות דפדפן למודל המארזים

סקריפטים של puppeteer-core (Chrome מקומי) שמריצים את המסכים והאשפים של המארזים
מול סביבה רצה, ובודקים דרך ה-API של האפליקציה שהמצב ב-DB נכון. נכתבו לבדיקת
הענף `feat/package-model` על מכונת הפיתוח (2026-09-17); התיקונים שהם מצאו
נמצאים ב-git log.

## דרישות

- Chrome ב-`C:\Program Files\Google\Chrome\Application\chrome.exe` (נתיב קבוע ב-`lib.mjs`).
- אפליקציה רצה מול DB ששודרג למודל המארזים עם **הקונפיגורציה של הפיתוח**:
  עמדת פתיחה = סוג 5 (אשף קליטה), סגירה = סוג 8 (בדיקת סביבה), סוג מארז 15
  ("מארז מגבר": מגבר הספק 6 + ערכת מחברים 11 + כבל תדר גבוה 10), מעבדת מחקר = סוג 9.
  המזהים האלה קבועים בראש כל סקריפט — לסביבה אחרת יש לעדכן אותם.
- משתמש Keycloak עם התפקידים manager + tester + storekeeper ומספר עובד.
  `node kc-test-user.mjs create` יוצר משתמש `pkgtest` (מספר עובד 9902) עם סיסמה
  אקראית ושומר אותה ב-`.e2e-user.json` (לא נכנס ל-git); `delete` מוחק אותו.
- `MINIO_PUBLIC_ENDPOINT` באפליקציה חייב להיות כתובת שהדפדפן מגיע אליה
  (על מכונת הפיתוח: `http://<IP המכונה>:9000`, לא `host.docker.internal`) —
  אחרת העלאות הצילומים באשף נכשלות בשקט.

## הרצה

```
set E2E_BASE=http://10.10.200.120
set E2E_USER=pkgtest
set E2E_PASS=<מ-.e2e-user.json>
node scripts/e2e-packages/01-smoke.mjs
```

או פשוט להשאיר את `.e2e-user.json` ליד הסקריפטים (`kc-test-user.mjs create` כותב אותו).

| סקריפט | מה בודק |
|---|---|
| `01-smoke.mjs` | כניסה, כל המסכים נטענים, ה-API של מארזים / סוגי מארז / משלוחים / חיפוש עונה נכון |
| `02-flow.mjs` | מחזור חיים מלא דרך ה-API: קליטה → פתיחה (התחלה קבוצתית, תוצאה לכל פריט + לקופסה) → פריטים בעמדות שלהם → נקודת המפגש (סטטוס 6) → סגירה → הושלם |
| `03-wizards-ui.mjs` | אשף הפתיחה ואשף הסגירה בדפדפן, כולל העלאות צילומים אמיתיות ל-MinIO, דיאלוגי מדבקות/עריכה/קליטה, החיפוש הגלובלי |
| `05-rules.mjs` | חוקים: שינוי סוג אחרי פתיחה (אזהרה + איפוס), פריט אחרון, מחיקה מדורגת, משלוח מצהיר סוגי מארז בלבד, API של הגדרות, פריט שסיים במחקר ולא הגיע לסגירה (דיאלוג ההחלטה) |
| `07-hydration.mjs` | שגיאות דפדפן בטעינה פשוטה של כל עמוד |

צילומי מסך נכתבים ל-`shots/`. כל סקריפט משחרר בתחילתו מארזים ש"נתקעו בבדיקה"
בעמדות הפתיחה/הסגירה מריצה קודמת שנקטעה.
