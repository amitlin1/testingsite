# מארזים — חבילת מסירה

הפרומפט המלא: **`IMPLEMENTATION_PROMPT.md`** — זה הקובץ שצריך להעביר ל-Claude Code.

## הארטבורדים (מקור האמת לעיצוב)

| ארטבורד | מה בתוכו |
|---|---|
| `Packages.dc.html` | רשימת מארזים, עמוד מארז, דיאלוג קליטה 1200px, דיאלוג מחיקה |
| `Testing Screen Packages.dc.html` | מסך הבדיקות עם תורי מארז, רצועת מארז בכרטיס פריט, אשפי פתיחה וסגירה, דיאלוג החלטה |
| `Package Types Settings.dc.html` | הגדרות → מארזים: סוגי מארז ועורך התכולה |
| `Shipments Packages.dc.html` | משלוחים לפי סוג מארז + כמות |
| `Package Dialogs.dc.html` | מדבקות, איפוס בשינוי סוג, עריכת מארז, הפריט האחרון |
| `Items.dc.html` | כרטיס "המארז שלי" בדיאלוג הפריט |
| `Settings.dc.html` | תג `מארז` בסוגי פריטים, תג `עמדה ברמת מארז` במסלולים |
| `TopNav.dc.html` | טקסט החיפוש הגלובלי |
| `Package Stations.dc.html` | ארטבורד עזר: שני האשפים לבד, לבדיקת מצבים |

בכל ארטבורד עם חלונות יש tweak **״תצוגת חלונות״** שפותח כל חלון ישר בטעינה.

## שתי החלטות מוצר שפתוחות

1. **בדיקות ה-RU** — הוצאו מאשף פתיחת המארז (שלבים 2 ו-6 באשף הישן). להוציא לגמרי, או להחזיר כשלב במסלול של הפריט?
2. **אשף ״קליטה וצילום״ הישן** — עדיין בקוד ולא נגיש מאף עמדה. למחוק במימוש.

## שני שדות שהשרת עדיין לא מחזיר

- מספר הפריטים שסיימו במארז (ל-`N/M סיימו`).
- רשימת הפריטים שלא הגיעו לעמדת הסגירה + העמדה שכל אחד נמצא בה (ל-`blocked_by`).
