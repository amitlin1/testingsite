# START HERE — מודל מארזים

חבילת מסירה להטמעת מודל **מארז** ב-`amitlin1/testingsite`.

## מה לקרוא, בסדר הזה

1. **`IMPLEMENTATION_PROMPT.md`** — הפרומפט. סכימה, API, תשעה מסכים, ערכי עיצוב, בדיקות קבלה. זה המסמך שמנחה את המימוש.
2. **`README.md`** — מפת הארטבורדים, שתי החלטות מוצר פתוחות, שני שדות חסרים בשרת.
3. **`design/`** — הארטבורדים עצמם. פותחים ישירות בדפדפן (`support.js` יושב לידם באותה תיקייה). הם מקור האמת לכל טקסט, מצב וערך עיצוב.

## איך לקרוא ארטבורד

הארטבורדים אינטראקטיביים — לחץ בהם כדי להגיע למצבים:

| קובץ | איך מגיעים למצבים |
|---|---|
| `Packages.dc.html` | לחיצה על שורה בוחרת מארז; `קליטת מארז` פותח את הדיאלוג; `מחיקה` בפאנל פותח את דיאלוג המחיקה |
| `Testing Screen Packages.dc.html` | בחר עמדה: **עמדת פתיחת מארז 1** / **עמדת סגירת מארז 1** לתורי מארז, **עמדה חשמלית A** לכרטיס פריט עם רצועת מארז. `התחל…` פותח אשף |
| `Package Dialogs.dc.html` | ארבעת הכפתורים בראש הדף פותחים כל דיאלוג |
| `Package Stations.dc.html` | שני האשפים לבד, לבדיקת שלבים ומצבי חסימה |
| `Package Types Settings.dc.html` | בחר סוג מארז מהרשימה; עורך התכולה נפתח מתחת |

בארטבורדים עם חלונות יש גם בורר **״תצוגת חלונות״** בפאנל ה-Tweaks שפותח כל חלון ישר בטעינה.

## מה חדש לגמרי ומה שינוי בקיים

**חדש:** `/packages`, `/packages/[id]`, `/settings/packages`, דיאלוג קליטת מארז, אשף פתיחת מארז, אשף סגירת מארז, דיאלוג מדבקות.

**שינוי בקיים:**
- מסך הבדיקות — סוגי עמדה ברמת מארז, כרטיסי מארז בתור, רצועת מארז בכרטיס הפריט, מזהה מלא בראש הכרטיס.
- אשף ״קליטה וצילום״ הישן (8 שלבים) — **נמחק**, מוחלף באשף פתיחת מארז (6 שלבים).
- משלוחים — יצירה לפי סוג מארז + כמות, עמודות מארזים.
- דיאלוג הפריט — כרטיס ״המארז שלי״.
- הגדרות — תג `מארז` בסוגי פריטים, תג `עמדה ברמת מארז` במסלולים.
- חיפוש גלובלי — כולל מארזים.

## הדבר האחד שהכי חשוב לא לפספס

**המזהה.** 16 ספרות: 14 בסיס משותף לכל המארז + 2 סיומת. `00` שמורה למארז, הפריטים `01` ומעלה. נוצר בשרת. מוצג מקובץ בקבוצות של 4 עם סיומת מודגשת, ועטוף ב-`direction:ltr; unicode-bidi:isolate` כדי שלא יתהפך ב-RTL. §0 בפרומפט.
